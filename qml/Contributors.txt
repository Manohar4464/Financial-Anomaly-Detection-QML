Project Contributors

This project, Financial Anomaly Detection using Quantum Machine Learning (QML), was developed as a collaborative effort for the All India Quantum Valley Hackathon (AQVH) 2025 and was successfully presented in the Semi-Final Round. The project demonstrates the practical application of Quantum Machine Learning (QML) for detecting anomalous financial transactions using a hybrid quantum-classical approach.

Each team member contributed to different phases of the project, including dataset preparation, backend development, quantum algorithm implementation, model evaluation, documentation, and presentation. The successful completion of this project was the result of effective teamwork, technical collaboration, and continuous knowledge sharing.
